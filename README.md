# Starbie
Starbie is a tiny motion controlled digital pet. It was created and designed by the guide of Half-life Hack Clubs guide and the guidance of LLMs in order to further explain instructions and help fill the missing gaps. These pieces came out of the start guide that was provided and you can make it too by going to https://github.com/SharKingStudios/Starbie/blob/main/Week%201%20Guide.md
